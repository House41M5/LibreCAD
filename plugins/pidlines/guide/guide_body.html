1P&ID คืออะไร

P&ID (Piping & Instrumentation Diagram) คือแบบที่บอกว่าระบบหนึ่งมีท่อ อุปกรณ์ วาล์ว เครื่องวัด และระบบควบคุมอะไรบ้าง ต่อกันอย่างไร และควบคุมกันอย่างไร โดยไม่สนตำแหน่งหรือระยะจริง (ไม่ตามมาตราส่วน · NTS)

ใช้ทำอะไร

  • ออกแบบและสั่งซื้อ นับวาล์ว เครื่องวัด และขนาดท่อจากแบบ
  • ติดตั้งและตรวจรับ ช่างเดินท่อและเดินสายตาม tag ในแบบ
  • เดินเครื่องและซ่อมบำรุง หาวาล์วที่ต้องปิดหรือเปิด จุดวัด และลูปควบคุม
  • ความปลอดภัย ใช้ทบทวนความเสี่ยง (เช่น HAZOP) และเลือกตำแหน่งวาล์วเมื่อไฟหรือลมดับ
  • ระบบข้อมูล tag ในแบบใช้เป็นชื่อจุดข้อมูลใน PLC, SCADA หรือระบบ IoT ได้ตรงกันทุกที่

P&ID ต่างจาก PFD อย่างไร

เรื่องPFD (Process Flow Diagram)P&ID
จุดประสงค์ภาพรวมกระบวนการ สมดุลมวลและพลังงานรายละเอียดสำหรับสร้าง เดินเครื่อง และซ่อมระบบ
อุปกรณ์อุปกรณ์หลักเท่านั้นทุกตัว รวมปั๊มสำรอง ตัวกรอง ถังเล็ก
ท่อเส้นทางไหลหลักทุกเส้น พร้อมขนาดและเลขท่อ
วาล์ว เครื่องวัดเฉพาะตัวที่สำคัญต่อการควบคุมทุกตัว พร้อม tag และชนิดสัญญาณ
ข้อมูลสภาวะอุณหภูมิ ความดัน อัตราไหล ตามจุดไม่ใส่ (อยู่ในเอกสาร datasheet)

ในแบบควรมีอะไร

ควรมี

  • อุปกรณ์ทุกตัว พร้อม tag และชื่อสั้น
  • ท่อทุกเส้น พร้อมเลขท่อ ขนาด และทิศการไหล
  • วาล์วทุกตัว รวม drain และ vent
  • เครื่องวัด ลูปควบคุม และชนิดสัญญาณ
  • อินเตอร์ล็อก และตำแหน่งวาล์วเมื่อไฟหรือลมดับ
  • ป้ายต่อแผ่นอื่น หมายเหตุ กรอบชื่อแบบ ประวัติแก้ไข

ไม่ควรมี (อยู่ในเอกสารอื่น)

  • ตำแหน่งและระยะท่อจริง → แบบ layout หรือ isometric
  • สายไฟ ขั้วต่อ ตู้ไฟ → loop diagram และแบบไฟฟ้า
  • spec ละเอียดของอุปกรณ์ → datasheet
  • รายละเอียดโปรแกรม PLC → เอกสาร control narrative

ชุดแบบและมาตรฐาน

ระบบหนึ่งมักมีหลายแผ่น แผ่นแรกเป็น legend (คำอธิบายสัญลักษณ์และตัวย่อ) แผ่นถัดไปแยกตามระบบ และแผ่นที่ต่อกันใช้ป้ายต่อแผ่นชี้หากัน

สัญลักษณ์เครื่องวัดและตัวอักษร tag ในคู่มือนี้ยึด ISA-5.1 ซึ่งใช้แพร่หลายในงาน process ส่วนสัญลักษณ์วาล์วและอุปกรณ์อิงแบบที่ใช้กันทั่วไป (เทียบกับตารางสัญลักษณ์ของ geminivalve.com) มาตรฐานอื่นที่อาจเจอคือ ISO 10628 และ ISO 14617 ซึ่งนิยมในยุโรป

ถ้าโครงการหรือลูกค้ามี legend ของตัวเอง ให้ยึด legend นั้นก่อนคู่มือนี้เสมอ และแนบ legend ไปกับชุดแบบทุกครั้ง

2กฎการเขียนแบบ

แผ่นแบบและมาตราส่วน

  • A3 แนวนอนเป็นขนาดที่ใช้มากที่สุด ระบบใหญ่ใช้ A1
  • P&ID ไม่ตามมาตราส่วน วาดทุกอย่างบนกระดาษ 1:1 หน่วยมิลลิเมตร สัญลักษณ์ในไลบรารีมีขนาดพอดี A3 แล้ว
  • เครื่องพิมพ์รับได้แค่ A4: ใช้แม่แบบ A4 (สัญลักษณ์ขนาดเท่าเดิม พื้นที่น้อยลง) หรือพิมพ์แบบ A3 ย่อลง A4 ที่ 71% (ตัวอักษร 2.5 มม. เหลือ 1.8 มม. ยังอ่านได้)

การจัดวาง

  • การไหลหลักจากซ้ายไปขวา ทางเข้าระบบอยู่ซ้าย ทางออกอยู่ขวา
  • ถังสูงและหอผึ่งเย็นอยู่บน ปั๊มอยู่ล่าง ใกล้ของจริงพอให้เข้าใจ
  • ท่อเป็นเส้นแนวนอนหรือแนวตั้ง หักมุม 90° ไม่ลากเฉียง
  • เส้นขนานห่างกันอย่างน้อย 7–10 มม. เผื่อที่เขียนเลขท่อ
  • เครื่องวัดอยู่ใกล้จุดที่วัด เส้นต่อสั้นที่สุด
  • เว้นที่ว่างไว้ แบบที่โล่งอ่านเร็วกว่าแบบที่อัดแน่น

{{SIGNALS}}

"ตัดเส้น" คือปลั๊กอินตัดเส้นใต้สัญลักษณ์ยาวตามค่า gap ใน pidlines.ini (มม. ที่สเกล 1) · "ไม่ตัด" คือวางทับเส้น

เลขท่อ (line number)

100 - CWS - 102

100 ขนาด DN (มม.) · CWS รหัสบริการ · 102 ลำดับท่อในระบบ
ขยายต่อได้ตามที่บริษัทใช้ เช่น 100-CWS-102-A1-N (A1 = spec ท่อ, N = ไม่มีฉนวน)

  • เขียนเหนือท่อ ขนานกับท่อ ท่อแนวตั้งหมุนตัวอักษร 90°
  • ท่อเปลี่ยนขนาด เปลี่ยนบริการ หรือแยกสาขา ต้องได้เลขใหม่
  • ลูกศร ann_flow วางบนท่อหลังจุดแยกและก่อนเข้าอุปกรณ์

4วาล์ว

วาล์วทุกตัววางบนแนวท่อ จุดแทรกอยู่กลางวาล์ว ยาว 6 มม. (เช็ควาล์ว 4 มม.) และต้องตัดท่อใต้วาล์วออก ด้วยคำสั่ง Line Gap (บทที่ 7) วาดบน layer PID-VALVE

{{SYM_VALVES}}

รูปที่แต่ละแหล่งวาดไม่เหมือนกัน เช่น gate valve บางบริษัทวาดเป็นรูปโบว์เปล่า ให้ใช้ตาม legend ของโครงการ และถ้าไม่แน่ใจว่าเป็นวาล์วชนิดไหน ใช้ vlv_generic แล้วเขียนชนิดไว้ข้างวาล์ว

เลือกวาล์วให้ตรงงาน

วาล์วเหมาะกับวาล์วเหมาะกับ
gateเปิดสุดหรือปิดสุด (isolation) ไม่ใช้หรี่globeหรี่ ปรับอัตราการไหล
ball / plugเปิด-ปิดเร็ว 1/4 รอบbutterflyท่อใหญ่ เปิด-ปิด หรือปรับหยาบ

actuator (หัวขับ)

แทรกตัววาล์วก่อน แล้วแทรก actuator ที่จุดเดียวกัน ก้านเริ่มที่กลางวาล์ว วาล์วควบคุม โซลินอยด์วาล์ว และวาล์วมอเตอร์มีแบบประกอบเสร็จในหมวด 1 Valves แล้ว ส่วนที่เป็นสีเทาในตารางคือตัววาล์วที่ไว้ให้เห็นตำแหน่ง

6เครื่องวัด

เครื่องวัดแต่ละตัวเขียนเป็นสัญลักษณ์ขนาด 10 มม. (ISA-5.1) รูปทรงบอกว่าเป็นอุปกรณ์แบบไหน เส้นกลางบอกว่าติดตั้งหรือแสดงผลที่ไหน วาดบน layer PID-INST

{{IMATRIX}}

เขียน tag ในวงกลม

  • บรรทัดบนคืออักษรบอกหน้าที่ เช่น TT, TIC บรรทัดล่างคือเลขลูป
  • อักษรเกิน 4 ตัวหรือวงกลมคับ ให้ขยายสัญลักษณ์ 1.2 เท่า แล้วขยับตัวอักษรตาม
  • เส้นต่อจากท่อใช้เส้นบางบน layer PID-PIPE-MINOR ลากถึงขอบวง ไม่เข้าไปถึงกลาง

  • grid: Options → Current Drawing Preferences ตั้ง grid 2.5 มม. แล้วเปิด snap to grid ตอนวางสัญลักษณ์และท่อ

ขั้นตอนเขียน

  1. เตรียมข้อมูลก่อนวาดร่างระบบบนกระดาษหรือจาก PFD ทำรายการอุปกรณ์ เครื่องวัด และเลขท่อ จะวาดเร็วและไม่ต้องย้ายของบ่อย
  2. วางอุปกรณ์หลักเลือก layer PID-EQUIP · Library Browser → PID → 4 Equipment → เลือกสัญลักษณ์ → Insert → ตั้ง Angle และ Factor ในแถบตัวเลือก → คลิกจุดวางบน grid
  3. ลากท่อlayer PID-PIPE-MAIN · Tools → Line → 2 Points (คำสั่ง li) ลากเป็นเส้นตรงทีละช่วง ใช้ LINE ไม่ใช้ polyline เพราะ Line Gap ตัดได้เฉพาะ LINE
  4. ใส่วาล์วแล้วตัดท่อlayer PID-VALVE · แทรกวาล์วที่จุดบนท่อ แล้วใช้ Tools → Modify → Line Gap (คำสั่ง gl) ตั้ง Gap size 6 (เช็ควาล์ว 4) · Line snap Free · Gap snap Middle แล้วคลิกที่กลางวาล์ว
  5. ใส่ actuator และตำแหน่งเมื่อดับแทรก actuator ลูกศร และตัวอักษร FO/FC ที่จุดเดียวกับวาล์ว หรือใช้แบบประกอบเสร็จ vlv_control vlv_solenoid vlv_motor
  6. วางเครื่องวัดlayer PID-INST · แทรกสัญลักษณ์ให้จุดศูนย์กลางอยู่บน grid แล้วลากเส้นต่อจากท่อบน layer PID-PIPE-MINOR ถึงขอบวง

รายการตรวจก่อนส่งแบบ

  • อุปกรณ์ทุกตัวมี tag และชื่อ
  • ท่อทุกเส้นมีเลขท่อ ขนาด และทิศการไหล
  • จุดเปลี่ยนขนาดท่อมีข้อลดและเลขท่อใหม่
  • วาล์วทุกตัวอยู่บนท่อที่ตัดช่องแล้ว ไม่มีเส้นทะลุวาล์ว
  • วาล์วควบคุมมี tag และตำแหน่งเมื่อดับ (FO/FC)
  • เครื่องวัดทุกตัวมีอักษรและเลขลูป รูปทรงและเส้นตำแหน่งถูก
  • ทุกตัวในลูปเดียวกันใช้เลขเดียวกัน
  • เส้นสัญญาณถูกชนิด ไฟฟ้า ลม หรือข้อมูล
  • ปั๊มมีวาล์วปิดทั้งสองด้าน และเช็ควาล์วด้านส่ง
  • จุดสูงมี vent จุดต่ำมี drain
  • ท่อที่ไปแผ่นอื่นมีป้ายต่อแผ่น และแผ่นปลายทางมีป้ายคู่กัน
  • เส้นตัดกันเว้นช่อง เส้นต่อกันเป็นตัว T
  • ตัวอักษรไม่ทับเส้น อ่านได้เมื่อพิมพ์ขนาดจริง
  • ทุกอย่างอยู่ถูก layer (ลองปิดทีละ layer ดู)
  • กรอบชื่อแบบครบ เลขแบบ ชื่อ วันที่ ผู้เขียน revision
  • แนบ legend ไปกับชุดแบบ
