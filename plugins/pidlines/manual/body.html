คู่มือปลั๊กอิน LibreCADPID signal line

วางสัญลักษณ์เส้นสัญญาณ P&ID (ISA-5.1) ลงบนเส้น ลายที่ต้องเว้นช่อง (o ◉ ตัวอักษร) ตัดเส้นใต้สัญลักษณ์ให้ ผลเป็นเส้นกับบล็อก DXF ธรรมดา เปิดในโปรแกรม CAD ไหนก็เหมือนกัน

LibreCAD 2.2.1.6 รุ่นแพตช์ (Kai)
ปลั๊กอิน pidlines · 12 ลาย
ฉบับ 20 ต.ค. 2569

1ลายในรายการ

{{ROWS}}
ตัวอย่างความหมาย · ไฟล์ลายช่องตัด mm

ภาพตัวอย่าง: เส้นยาว 24 สเกล 1 ระยะห่าง 8 (ลายตัวอักษรใช้ระยะห่างตั้งต้น 40 จึงได้ตัวเดียวกลางเส้น) · ช่องตัดเป็นค่าที่สเกล 1 จาก pidlines.ini

2วิธีใช้

  1. หลายเส้น: ลากกรอบเลือกเส้นไว้ก่อน เพราะตอนปลั๊กอินรอให้เลือก ลากกรอบไม่ได้ คลิกได้ทีละเส้น
  2. เมนู Plugins → PID signal line
  3. ตั้งค่าในหน้าต่าง แล้วกด OK

  4. คลิกเส้นบนแบบ (เส้นที่ตัดแล้ว คลิกท่อนเดียวพอ) แล้วกด Enter · ถ้าเลือกไว้แล้วตามข้อ 1 กด Enter ได้เลย · Esc = ยกเลิก ไม่วางอะไร
{{DIAGRAM}}

สัญลักษณ์เรียงกึ่งกลางเส้น ปลายสองข้างเหลือเท่ากัน · จำนวน = ความยาว ÷ ระยะห่าง ปัดลง (อย่างน้อย 1 ตัว) · เดินตามโค้ง fillet และมุมของ polyline

3เปลี่ยน · ลบ · ย้อน

  • เปลี่ยนลายหรือระยะห่าง: รันซ้ำ แล้วคลิกท่อนใดก็ได้ของเส้นเดิม ลายเดิมถูกลบ เส้นต่อกลับเป็นเส้นเดียวก่อน แล้วจึงวางลายใหม่
  • เอาลายออก: เลือก “(ลบสัญลักษณ์อย่างเดียว · ต่อเส้นกลับ)”
  • วางผิด: Ctrl+Z ย้อนการวางทั้งรอบ

4ข้อควรรู้

  • ใช้กับ line · arc · polyline เท่านั้น วัตถุอื่นในที่เลือกถูกข้าม
  • ท่อนเส้นกับสัญลักษณ์อยู่ layer ของเส้นเดิม สี ชนิดเส้น ความหนาตามเส้นเดิม
  • ลายลม // เอียงทางเดียวกันทุกแนวเส้น · L บนเส้นแนวตั้งตั้งตรงเหมือนแนวนอน · ตัวอักษร CWS … ไม่กลับหัว อ่านจากซ้ายไปขวาเสมอ
  • ใกล้มุม ปลายเส้น หรือระยะห่างแคบกว่าช่อง: สัญลักษณ์วางทับเส้นโดยไม่ตัด และมีกล่องแจ้งจำนวน
  • ลาย “ไม่มีตัวนำ” ลบเส้นฐานทิ้ง เหลือแต่คลื่น
  • หลังตัดแล้ว อย่าย้ายหรือ trim ท่อนเส้นเอง ไม่งั้นต่อกลับไม่ได้ ต้องลบสัญลักษณ์ที่ค้างเอง
  • แก้ไฟล์ลาย .dxf ทีหลัง แบบที่มีบล็อก pid_… อยู่แล้วยังใช้บล็อกเดิม: ลบสัญลักษณ์ด้วยปลั๊กอินก่อน แล้วลบบล็อกใน Block List
  • layer ที่ปิดการพิมพ์ไว้ เส้นจะไม่ออกตอนพิมพ์
  • ต้องใช้ LibreCAD รุ่นแพตช์ รุ่นปกติ 2.2.1.x เลือกเส้นแล้วไม่เกิดอะไร

5เพิ่มลายเอง

  1. วาดสัญลักษณ์รอบจุด (0,0) ให้เส้นวิ่งตามแกน X · layer 0 · สี ByBlock · หน่วย mm ที่สเกล 1
  2. เซฟเป็น pid_<ชื่อ>.dxf ใน Documents\LibreCAD\pidlines
  3. เพิ่มหัวข้อ [<ชื่อ>] ใน pidlines.ini โฟลเดอร์เดียวกัน เช่น 
    [cws]
label="น้ำหล่อเย็น จ่าย (cooling water supply)  —CWS—"
gap=7.75      ; ช่องตัด mm ที่สเกล 1 (0 = ไม่ตัด)
spacing=40    ; ระยะห่างตั้งต้นในหน้าต่าง
; line=0      ; ลายที่ไม่มีเส้น (ลบเส้นฐาน)
; mirror_steep=1 ; เส้นชันเกิน 45° วางแบบสะท้อน (//, L)
; upright_vertical=1 ; เส้นแนวตั้ง ไม่หมุนสัญลักษณ์ (L)
  4. รหัสตัวอักษรใหม่ (เช่น CHWS) สร้างได้ทั้งไฟล์ลายและหัวข้อ ini ด้วยสคริปต์ในซอร์สปลั๊กอิน (ต้องมี Python + ezdxf): 
    python make_text_patterns.py "%USERPROFILE%\Documents\LibreCAD\pidlines" "CHWS=น้ำเย็น จ่าย"

ไม่ต้องปิดเปิด LibreCAD ปลั๊กอินอ่านลายใหม่ทุกครั้งที่เปิดหน้าต่าง

ไฟล์อยู่ที่ Documents\LibreCAD\plugins\pidlines0.dll ตัวปลั๊กอิน
Documents\LibreCAD\pidlines\ ลายเพิ่ม + pidlines.ini (ชื่อซ้ำ ใช้ของที่นี่)
C:\Program Files\LibreCAD\resources\pidlines\ ลายพื้นฐาน 4 ลาย
%APPDATA%\LibreCAD\pidlines.ini ค่าที่หน้าต่างจำไว้
